# OverTheWire Writeups

Hi! Here is my repository for some of the [OverTheWire](https://overthewire.org/wargames/) wargames i've done. Each wargame comes under a different theme in security. 

I strongly recommend giving them a go yourself as it is very fun and satisfying once you learn/get how to solve the challenges - I hope you enjoy :)

> Flags also get randomised every now and again anyways so no guarentees that the flags will be the same when you try them

> [Narnia](./Narnia/Narnia.md): Binary exploitation/Memory corruption\
